# PDF Privacy Cleaner — 단계 1

무료 브라우저 기반 PDF 개인정보 탐지 프로토타입입니다. **아직 익명화 또는 영구 삭제를 수행하지 않습니다.**

## 실행

Node.js 20.19+ 또는 22.12+ 권장.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 열어 테스트합니다.

## 구현 완료
- 텍스트 PDF 불러오기 (30MB 이하)
- PDF.js 페이지 렌더링 및 텍스트 추출
- 이름 필드, 학번 필드, 이메일, 전화번호 후보 탐지
- 탐지 후보 선택/해제
- 두 가지 미래 출력 모드 선택 UI

## 아직 구현되지 않음
- 사용자 명단 대조 및 서술형 문장 속 이름 탐지
- 정확한 개인정보 좌표 매핑, 교사 수동 영역 선택
- PDF 영구 교정 및 안전한 재구성
- 주석/첨부파일/메타데이터 정리 및 결과 검증
- PDF 다운로드

## 개인정보 보호 주의
실제 학생 정보 대신 가상 데이터로 테스트하세요. 외부 API를 호출하지 않는 구조이나, 배포 전에는 정적 호스팅·의존성·브라우저 확장 프로그램의 개인정보 위험도 점검해야 합니다. PDF의 미리보기 이미지가 브라우저 메모리에 존재할 수 있습니다.

## 다음 단계 제안
1. PDF 텍스트 항목의 좌표 매핑과 탐지 결과 하이라이트
2. 교사의 수동 영역 선택과 학생 명단 기반 이름 탐지
3. 원본 유지형의 검증 가능한 영구 교정 엔진 통합
4. 응답 재구성형의 구조 추출 및 새 PDF 생성
5. 자동 검증 + 수동 검토 + 다운로드 게이트
